# 이관된 원본 참고본

README/ci.yml.txt는 당시 원문이며 현재 운영 지시가 아니다. kubernetes/base는 임시 fds 배포, d-sec-01의 일부 파일은 앱·Monitoring·CI namespace/ServiceAccount가 섞여 있다. 이관 자체로 정본 인수를 주장하지 않는다.

이 디렉터리의 manifest를 일괄 적용하지 않는다. 앱 전용 배포본은 infra-kubernetes PR #7의 독립 검토·병합 및 정본 AC와 대조한 뒤 별도 PR로 구성한다. Root README와 docs/POLICY.md가 새 저장소의 검토 정책이다.
